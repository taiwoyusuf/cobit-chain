# Demo Script

## Executive demo

1. Open demo/index.html.
2. Scroll to Executive Demo Control Panel.
3. Click Run PROCEED Demo.
4. Explain: the wearable captured context and asked mock Platform B if the action can proceed.
5. Scroll to Glasses HUD Presenter Mode.
6. Click Open Fullscreen HUD.
7. Explain: the glasses display Platform B output; they do not decide.
8. Scroll to Device Readiness Passport.
9. Generate Device Passport.
10. Scroll to ServiceNow / CI Context Mock Adapter.
11. Build CI Context Packet.
12. Scroll to Validation / Change Control Context Mock Adapter.
13. Build Validation Context Packet.
14. Scroll to Human Authority / Training / Shift Context Mock Adapter.
15. Build Human Authority Packet.
16. Scroll to Integrated Assurance Context Fusion Panel.
17. Click Run Complete Fusion Demo.
18. Scroll to MVP Readiness Report.
19. Click Run Complete Report Demo.
20. Scroll to MVP Acceptance Test Runner.
21. Click Run MVP Acceptance Test.
22. Scroll to Handoff Package Builder.
23. Click Build Handoff Package.

## Risk-path demo

1. Run HOLD Demo.
2. Explain missing reviewer or authority context.
3. Run ESCALATE Demo.
4. Explain context mismatch or higher-risk condition.
5. Show Audit Challenge Panel.
6. Generate audit questions.
7. Show Event Replay.
8. Run replay to reconstruct the event.
