## Architecture boundary

Thread D does not redesign Platform B.

Thread D does not replace Platform B.

Thread D does not make regulated decisions.

Thread D captures, displays, relays, reconstructs, and packages context evidence.

Platform B remains the assurance decision engine.

## Current limitations

This MVP is local mock only.

It does not connect to:

- real Platform B API
- ServiceNow
- QMS
- RFID
- NFC
- Halo hardware
- GMP systems
- production APIs

It does not modify:

- GMP records
- audit trails
- deviations
- CAPA
- validation records
- work orders
- CMDB records
- access records
