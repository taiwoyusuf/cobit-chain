# Thread D - RAMAT Vision Context Witness MVP

## Purpose

Thread D demonstrates how a wearable or mobile endpoint can act as a controlled context witness for regulated operational work.

The endpoint can capture context, display a Platform B decision, support audit reconstruction, and package mock evidence.

## Core principle

Any device may witness. Only Platform B decides.

## What this MVP shows

- RAMAT Vision / ELSA / OMA / Halo-style wearable endpoint behavior
- Context capture from a simulated asset
- Mock Platform B action admissibility decision
- PROCEED / HOLD / ESCALATE micro-decision display
- Action evidence package
- Evidence history
- Audit challenge questions
- Event replay
- Mock Platform B connector preview
- Device readiness passport
- ServiceNow / CI context mock adapter
- Validation / change control context mock adapter
- Human authority / training / shift context mock adapter
- Integrated assurance context fusion
- MVP readiness report
- MVP acceptance test
- Handoff package builder

## How to run

Open:

demo/index.html

demo/ramat-context-witness-demo.html

## Fast demo path

1. Scroll to Executive Demo Control Panel.
2. Click Run PROCEED Demo.
3. Open Glasses HUD Presenter Mode.
4. Run Device Readiness Passport.
5. Run ServiceNow / CI Context Mock Adapter.
6. Run Validation / Change Control Context Mock Adapter.
7. Run Human Authority / Training / Shift Context Mock Adapter.
8. Run Integrated Assurance Context Fusion Panel.
9. Run Thread D MVP Readiness Report.
10. Run Thread D MVP Acceptance Test Runner.
11. Build Thread D Handoff Package.

## Boundary

This is a local mock simulator only.

It does not connect to real Platform B, ServiceNow, QMS, RFID, NFC, Halo hardware, GMP systems, or production APIs.

It does not modify GMP records, audit trails, deviations, CAPA, validation records, work orders, CMDB records, or access records.

## Final statement

The glasses do not prove the work. The glasses initiate and display the proof chain. Platform B remains the decision engine.
