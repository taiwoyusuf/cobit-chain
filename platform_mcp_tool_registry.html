AI tools must produce evidence, not unsupported answers.

This module strengthens the existing MCP Server page by adding a live tool registry and demo tool-call evidence. Each tool has a purpose, input schema, output contract, allowed actions, blocked actions, evidence requirement, replay requirement, and risk level.
MCP governance rule: an AI agent should not invent operational trust. It should call a governed tool, retrieve evidence, respect blocked actions, return limitations, and produce a replayable tool-call record. Azure executes. COBIT-Chain proves.
