# Assurance OS Integrated Runtime

This is a local, deterministic, simulator-first Platform B1 implementation.

## Authority model

Platform B1 evaluates assurance state. RAMAT-compatible contracts display or witness evaluated state only. An identified accountable human remains the only binding authority.

## Safety boundary

No production connection, cloud deployment, PHI, company production data, external API call, autonomous approval, release decision, or physical-device integration is permitted.

## Deferred execution

Tests, tamper scenarios, evidence generation, backup verification, reconstruction, and inspection-bundle generation remain deferred to Step 170D and require separate human authorization.
