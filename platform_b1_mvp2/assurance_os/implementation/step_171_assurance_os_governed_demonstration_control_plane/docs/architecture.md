# Component Architecture

The control plane consumes immutable Step 170 references and Platform B1 action-admissibility
states. It performs local deterministic session orchestration, preflight, evidence and dependency
verification, source-state agreement review, identity and authority revalidation, No-Bind control,
accountable-human handoff, audit lineage, assurance passport preparation, display-only contract
preparation, and inspection reconstruction preparation.

Authority is preserved: Platform B1 decides assurance, source systems remain authoritative,
RAMAT Vision and Thread D2 display only, and only an identified accountable human may bind.
