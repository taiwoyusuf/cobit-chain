# Thread D2 Display Contract — Platform B1 MVP2 Outputs

## Purpose

Define how Thread D2 / RAMAT Vision MVP2 should display Platform B1 advanced assurance states.

## Core Rule

Platform B1 thinks.

Thread D2 shows.

RAMAT Vision displays the assurance state.

The glasses do not decide.

## Required Display Fields

Each D2 card should support:

- feature name
- depth level
- input context
- Platform B1 result
- status badge
- reason
- evidence state
- required action
- guardrail
- MVP2 Preview badge

## Example Display — Workflow Dependency Assurance Lens

Feature:

Workflow Dependency Assurance Lens

Display:

WORKFLOW APPEARS COMPLETE BUT BLOCKED

Reason:

LIS HOLD DETECTED

Missing:

Mandatory audit/accountability field

Action:

SECONDARY REVIEW REQUIRED

Evidence state:

AUDIT EVIDENCE NOT READY

Guardrail:

RAMAT Vision displays. Platform B1 evaluates. Source systems remain authoritative.
