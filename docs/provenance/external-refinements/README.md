## Rules

1. A concept may be documented publicly before implementation.
2. Documentation status must be explicit: PRIOR_INTERNAL_CONCEPT, EXTERNAL_REFINEMENT, ROADMAP_ONLY, CANDIDATE, IMPLEMENTED, VERIFIED.
3. An external post does not become COBIT-Chain authorship merely because it is incorporated.
4. Where COBIT-Chain evidence predates an external source, link the earlier artifact/commit/publication and hash it.
5. Where the external source is earlier, attribute it and classify the COBIT-Chain change as an external refinement.
6. GitHub timestamps establish a public repository record from the commit date onward; they do not retroactively prove earlier conception.
7. Frozen Canonical Audit R3 artifacts must not be edited by this package.
