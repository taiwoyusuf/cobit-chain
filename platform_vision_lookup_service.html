Thread B / Wearable Service / QR and Asset Lookup

The first live lookup flow for Governance Vision.

This service turns the wearable idea into a working Platform A/B flow. A user can scan or type an asset ID, retrieve a privacy-safe HUD response, view trust score and evidence confidence, and receive a controlled next action without exposing sensitive records.
Lookup principle: The first wearable interface must be read-only, privacy-filtered, and evidence-backed. It should return status, confidence, limitations, and next action. It must not approve work, modify records, bypass SOPs, or expose sensitive evidence in HUD mode.
