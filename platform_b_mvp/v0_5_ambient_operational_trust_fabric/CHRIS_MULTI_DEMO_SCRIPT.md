# Chris Multi-Demo Script

## Document status

PLATFORM B V0.5 NON-CONFIDENTIAL MULTI-DEMO SCRIPT

## Purpose

This script gives a concise non-confidential explanation of Platform B v0.5 Ambient Operational Trust Fabric for a multi-demo walkthrough.

## Opening

Platform B v0.5 extends Governance Vision from wearable capture into a device-agnostic operational trust fabric.

The core idea is simple:

The device senses. Platform B assures.

A future regulated site will not only be monitored. It will be trust-aware.

## Key phrase

Quiet when trusted. Alert when trust is at risk. Evidence when action is challenged.

## Demo positioning

This is a controlled non-production demonstrator.

It does not replace GMP systems, QMS, MES, LIMS, EMS, Lasair, validated workflows, or human review.

It shows how context witnesses can become assurance evidence.

## Demo 1 - Endosafe Backup Guardian

The operator scans or enters the Endosafe area.

If backup evidence is current, Platform B remains quiet.

If backup evidence is missing, Platform B raises a Yellow review alert.

If closure is attempted without evidence, Platform B raises a Red action-not-admissible alert.

## Demo 2 - Speedy Glove Black Box Evidence Gateway

Speedy Glove does not need to connect directly to Platform B.

A QR tag, NFC tag, wearable photo or video, manual upload, or M5Stack node can make the equipment assurance-visible.

The equipment does not need to be connected to be assurance-visible.

## Demo 3 - CleanroomTrust

The operator scans a cleanroom or hood.

Platform B checks cleaning evidence, environmental status, personnel readiness, certification, SOP step, reviewer, and evidence gaps.

Cleanroom readiness is not a room state. It is an evidence state.

## Demo 4 - Lasair / EMS Evidence Overlay

Lasair measures.

EMS monitors.

Platform B proves whether the environmental evidence is admissible for action.

Platform B does not replace either system.

## Demo 5 - IRLT Dose-Time Evidence Assurance

Radiopharma is time-sensitive.

Platform B treats time as part of product quality.

It checks dose timing, QC evidence, release evidence, chain of custody, room or equipment state, reviewer, and shipment or readiness window.

## Walkthrough close

Platform B v0.5 is not about adding more sensors.

It is about turning existing and low-cost signals into operational trust evidence.

The device senses.

Platform B assures.
