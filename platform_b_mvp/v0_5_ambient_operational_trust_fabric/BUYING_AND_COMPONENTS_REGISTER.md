# Buying and Components Register

## Document status

PLATFORM B V0.5 BUYING / COMPONENTS REGISTER

## Purpose

This register lists candidate demo components for Platform B v0.5 Ambient Operational Trust Fabric.

This is not a purchasing approval.

This is not a production architecture.

## Buying principle

Buy only what supports a controlled demo.

Do not buy equipment for production use.

Do not connect to real GMP systems.

Do not capture confidential or regulated evidence.

## Minimum demo kit

Minimum viable v0.5 kit:

1. phone
2. QR code labels
3. wearable capture device
4. M5Stack or ESP32 device
5. local HTML demo pages
6. optional Azure Function or IoT demo backend

## Strongest physical demo

A strong physical demo can show:

1. QR scan of Endosafe area
2. wearable photo/video capture
3. M5Stack button press or sensor event
4. Platform B Yellow alert for missing backup evidence
5. Platform B Red alert if closure is attempted without evidence
6. exportable evidence summary

## Suggested first purchase order

1. Ray-Ban Meta or existing wearable capture device
2. NFC tags
3. QR labels
4. M5Stack Atom / Core / StickC
5. BLE beacon
6. temperature and humidity sensor

## Guardrail

No patient data.

No real GMP batch data.

No confidential company information.

No production compliance claim.

No validated-use claim.

## Doctrine

The device senses. Platform B assures.

## Protected phrase

Quiet when trusted. Alert when trust is at risk. Evidence when action is challenged.
