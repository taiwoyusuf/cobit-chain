## Purpose

Platform B v0.5 extends Governance Vision from wearable capture into a device-agnostic wearable and IoT assurance fabric.

The goal is to support many controlled live demos using smart glasses, phones, QR codes, NFC tags, BLE beacons, ESP32/M5Stack nodes, Azure IoT Hub, Azure IoT Central, Azure Functions, Blob Storage, Azure Vision, SignalR, and Platform B assurance logic.

## Core doctrine

The device senses. Platform B assures.

## Stronger doctrine

The future regulated site will not only be monitored. It will be trust-aware.

## Protected phrase

Quiet when trusted. Alert when trust is at risk. Evidence when action is challenged.

## Definition

Ambient Operational Trust Fabric is a device-agnostic assurance fabric where wearables, QR tags, beacons, sensors, IoT devices, cleanroom signals, batch context, and human actions become context witnesses.

Platform B converts those signals into:

- evidence records
- context-assurance signals
- action admissibility decisions
- operational trust scores
- exception-only alerts
- exportable evidence summaries

## v0.5 demo tracks

### Demo 1 — Endosafe Backup Guardian

An operator enters or scans the Endosafe area. Platform B checks whether backup evidence is current.

If backup evidence is current, Quiet Assurance Mode remains silent.

If backup evidence is missing, Platform B creates a Yellow alert:

Endosafe backup evidence missing. Review required.

If closure is attempted without evidence, Platform B creates a Red alert:

Action not admissible.

### Demo 2 — Speedy Glove Black Box Evidence Gateway

Speedy Glove does not communicate directly across the network.

Platform B does not touch or control the equipment.

A QR/NFC tag, wearable photo/video, manual evidence upload, or external M5Stack evidence node makes the equipment assurance-visible.

Doctrine:

The equipment does not need to be connected to be assurance-visible.

### Demo 3 — CleanroomTrust

A cleanroom or compounding hood is scanned.

Platform B checks:

- cleaning evidence
- environmental monitoring status
- temperature/humidity/pressure signal
- personnel readiness
- room/hood certification
- SOP step
- required reviewer
- evidence gaps

Result:

Green / Yellow / Red readiness state.

Doctrine:

Cleanroom readiness is not a room state. It is an evidence state.

### Demo 4 — Lasair / EMS Evidence Overlay

Particle monitoring and EMS data exist in separate systems.

Platform B does not replace Lasair or EMS.

Platform B ingests or simulates their evidence status and decides whether environmental evidence is sufficient for action.

Doctrine:

Particle counters measure. EMS monitors. Platform B proves whether the environment is admissible for action.

### Demo 5 — IRLT Dose-Time Evidence Assurance

A radiopharma or IRLT workflow is time-sensitive.

Platform B checks:

- isotope/dose timing
- QC evidence
- release evidence
- chain of custody
- room/equipment state
- human reviewer
- shipment/readiness window

Doctrine:

In radiopharma, time is part of product quality.
