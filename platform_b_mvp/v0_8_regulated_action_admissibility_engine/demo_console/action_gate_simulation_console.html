Action Gate Simulation Console

Simulates how an action request passes through eligibility, evidence sufficiency, admissibility, exception mapping, human review, and evidence packet generation.

  1. Select action scenario.
  2. Load runtime context.
  3. Evaluate eligibility.
  4. Score evidence sufficiency.
  5. Map exceptions.
  6. Generate admissibility decision.
  7. Route human review when required.
  8. Generate evidence packet when required.
