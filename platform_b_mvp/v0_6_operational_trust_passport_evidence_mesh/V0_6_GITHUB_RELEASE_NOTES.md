# Platform B v0.6 GitHub Release Notes

## Release title

Platform B v0.6 - Operational Trust Passport and Ambient Evidence Mesh

## Release tag

platform-b-v0.6-operational-trust-passport-evidence-mesh

## Summary

Platform B v0.6 extends the v0.5 Ambient Operational Trust Fabric into a structured operational trust layer.

v0.6 introduces Operational Trust Passports, Ambient Evidence Mesh relationships, Action Admissibility Ledger records, Context Witness Chains, Reviewer Evidence Packets, Exception-Only Alerts, and Site Readiness Trust State.

## Core doctrine

A regulated action is not trusted because one signal is green. It is trusted when the evidence mesh agrees.

## Continuity from v0.5

The device senses. Platform B assures.

Quiet when trusted. Alert when trust is at risk. Evidence when action is challenged.

## Research and IP positioning

v0.6 strengthens Platform B as a controlled demonstrator for Assurance Engineering and Controlled Environment Assurance Engineering.

It supports the doctrine that the environment is part of the evidence.

It also strengthens the concept that site readiness is not a single room, sensor, dashboard, or equipment state. Site readiness is an evidence state across people, rooms, equipment, procedures, environmental signals, time, evidence, review, exceptions, and action context.
