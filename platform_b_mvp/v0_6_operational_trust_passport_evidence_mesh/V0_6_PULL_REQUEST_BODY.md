# Platform B v0.6 Pull Request

## Title

Platform B v0.6 - Operational Trust Passport and Ambient Evidence Mesh

## Summary

This pull request merges Platform B v0.6 into main.

v0.6 extends the v0.5 Ambient Operational Trust Fabric into a structured operational trust layer using passports, evidence mesh relationships, admissibility records, witness chains, reviewer packets, exception-only alerts, and site readiness trust state.

## Core doctrine

A regulated action is not trusted because one signal is green. It is trusted when the evidence mesh agrees.

## Continuity from v0.5

The device senses. Platform B assures.

Quiet when trusted. Alert when trust is at risk. Evidence when action is challenged.

## Research and IP positioning

v0.6 strengthens Platform B as a controlled demonstrator for Assurance Engineering and Controlled Environment Assurance Engineering.

It supports the doctrine that the environment is part of the evidence.

It also strengthens the concept that site readiness is not a single sensor state. It is an evidence state across people, rooms, equipment, procedures, environmental signals, time, review, exceptions, and action context.

## Guardrails

This is a controlled non-production demonstrator.

It does not support patient use, batch release, shipment release, clinical use, regulatory submission use, validated GMP use, autonomous execution, or production compliance.

It does not replace QMS, MES, LIMS, EMS, Lasair, validated systems, or human review.

No patient data, real GMP batch data, confidential company information, or regulated production data is included.
