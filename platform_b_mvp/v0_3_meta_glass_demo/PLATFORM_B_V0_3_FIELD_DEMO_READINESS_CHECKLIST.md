## Purpose

This checklist confirms the practical steps required before showing the Platform B v0.3 Meta Glass Wearable Field Demo to a reviewer.

## Pre-demo hardware checklist

- [ ] Ray-Ban Meta smart glasses are available.
- [ ] Meta AI app is installed.
- [ ] Glasses are paired with phone.
- [ ] Photo capture tested.
- [ ] Short video capture tested.
- [ ] Media import to phone tested.
- [ ] Share/export from phone tested.
- [ ] Upload into Platform B wearable capture page tested.

## Data protection checklist

- [ ] Demo area is non-confidential.
- [ ] No patient information is visible.
- [ ] No employee personal information is visible.
- [ ] No confidential company information is visible.
- [ ] No real GMP batch data is visible.
- [ ] No real validation or quality record is visible.
- [ ] No credentials, badges, passwords, QR codes, access tokens, restricted screens, or restricted facility details are visible.

## Platform B demo checklist

- [ ] wearable_capture.html opens on mobile or browser.
- [ ] Demo operator field is populated.
- [ ] Demo location field is populated.
- [ ] Demo equipment ID is populated.
- [ ] Demo SOP step is populated.
- [ ] Wearable evidence file uploads successfully.
- [ ] Context-assurance signal is generated.
- [ ] Action admissibility result is generated.
- [ ] Operational trust score update is generated.
- [ ] Evidence record appears in wearable_evidence_console.html.
- [ ] Exportable summary opens in wearable_evidence_summary_export.html.

## Reviewer success checklist

The reviewer can see:

- [ ] one wearable-captured photo or video
- [ ] one evidence ID
- [ ] one context-assurance signal
- [ ] one action admissibility result
- [ ] one operational trust score update
- [ ] one exportable evidence summary
