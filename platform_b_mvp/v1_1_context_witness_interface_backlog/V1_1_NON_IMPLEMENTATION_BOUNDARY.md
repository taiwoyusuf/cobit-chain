# Platform B v1.1 - Non-Implementation Boundary

## Purpose

Define what the Platform B v1.1 Context Witness Interface backlog package does not do.

## Boundary statement

This package is a backlog definition package.

It does not implement production software.

It does not reopen Platform B v1 architecture.

It does not replace Platform B v0.9 or v0.9.1.

It does not change Platform B decision logic.

It does not change admissibility rules.

It does not change validated systems.

It does not create GMP record authority.

## Device boundary

RAMAT Vision devices display, capture, translate, relay, and review.

RAMAT Vision devices do not become the decision engine.

Platform B decides.

## Audit boundary

RAMAT Vision Pro Audit Mode is read-only by default.

It may display, reconstruct, request, and draft observations.

It does not approve work, release batches, close deviations, close CAPA, alter audit trails, or modify GMP records.

## Translation boundary

Translation support may assist communication.

Translation support does not approve work.

Controlled documents remain the source of truth.

## AI boundary

AI recommendations may support review.

AI output is not approval.

## Quality system boundary

This backlog does not replace QMS, MES, LIMS, EMS, Lasair, validated systems, quality review, regulatory review, cybersecurity review, legal review, or human approval.
