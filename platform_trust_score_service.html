Service Route: /platform/trust-score-service
Thread B / Service Layer / First Callable Trust Engine

The first real service behind the Platform A/B architecture.

The Trust Score Service converts static dashboard claims into a callable scoring model. It accepts evidence signals, ownership state, support group state, access readiness, validation context, open gaps, MCP replay status, and observability readiness, then returns a score, decision class, confidence, explanation, and recommended action.
Trust-score principle: A score is not a decoration. It must be explainable, evidence-weighted, replayable, and conservative when data is missing. This service is the starting point for Platform B: APIs, MCP tools, Governance Vision, Evidence Store, and Operational Trust Twins can all call the same trust logic.

COBIT-Chain Trust Score Service is a demo service layer for Platform A/B. It does not replace QA approval, validation, cybersecurity review, ServiceNow governance, change control, or regulated decision-making.
